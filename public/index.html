DBI WebUSB Backend

Chưa kết nối
Trình duyệt hoặc thiết bị này không hỗ trợ WebUSB. Hãy mở trang này bằng Google Chrome hoặc Microsoft Edge (bản mới) trên máy tính macOS, Windows, Linux hoặc ChromeOS. Safari, Firefox và các trình duyệt trên iPhone/iPad không hỗ trợ.
Trên Switch: mở DBI → "Run MTP/USB" (chế độ cài từ USB).

Chưa kết nối
Trên Switch: mở DBI và bật chế độ MTP. Chế độ này khác chế độ cài đặt qua USB, hai chế độ không dùng cùng lúc. Duyệt và tải file về máy ở mọi kho. Riêng kho "SD Card" còn cho tạo thư mục, đổi tên, xoá và tải lên file/thư mục (mỗi file nhỏ hơn 4 GiB; kéo thả vào danh sách cũng được).
